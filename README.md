# Python Internship Projects – InternPe

## 📌 Internship Overview

This repository contains the projects I completed during my Python Programming Internship at InternPe. The projects were developed using Python and Tkinter to improve my programming, GUI development, and problem-solving skills.

## 📂 Projects Included

### 🕒 Digital Clock
A real-time digital clock that displays the current system time.

### 🐍 Snake Game
A classic Snake Game with score tracking and collision detection.

### ❌ Tic Tac Toe
A two-player Tic Tac Toe game with winner and draw detection.

### 🔴 Connect Four
A two-player Connect Four game with automatic win detection.

### 🏓 Pong Game
A two-player Pong game with score tracking and winner declaration.
